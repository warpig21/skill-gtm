# Skill GTM

Le skill che Claude usa per il lavoro di go-to-market, raccolte in un plugin da installare nel proprio Claude. Quando Matti aggiorna una skill qui, il Claude di tutti riceve la versione nuova.

## Cosa c'è

| Plugin | Cosa contiene |
|---|---|
| `gtm-skills` | 114 skill GTM in inglese (outreach, prospecting, segnali, ricerca, posizionamento) prese da [swan-gtm/gtm-skills](https://github.com/swan-gtm/gtm-skills), licenza MIT. Ogni skill ha in testa una nota per il mercato italiano. |

## Le regole che valgono sempre

- Le skill sono pensate per il mercato americano: numeri, canali e toni vanno adattati al mercato italiano.
- Nelle bozze non devono finire i nomi delle aziende che gli autori citano come esempio (per esempio Frontal, Impactable, Neon Triforce).
- Se il cliente ha un GTM Brain nel repo `warpig21/clienti`, Claude lo legge prima: quello che dice il Brain vale più di quello che dice una skill.

## Chi modifica

Le skill le aggiorna Matti. Chi vuole proporre una modifica la scrive a Matti.
